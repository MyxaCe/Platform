## Технический долг

Единый список того, что осознанно отложено. Ведётся с 2026-07-19, обновлён 2026-07-21.

### P0 — до реальных денег или до публичного адреса

- [ ] **Закрыть `POST /admin/users`** — dev-эндпоинт без какой-либо защиты, создаёт пользователя.
      На публичном адресе это открытая регистрация кому угодно. [[gateway]], ADR-018
- [ ] **Подтверждение почты при регистрации** — сейчас аккаунт активен сразу. Нужен почтовый
      сервис (SMTP/провайдер), его надо выбрать. ADR-018
- [ ] **Восстановление пароля** — одноразовая ссылка с коротким сроком жизни. Упирается в тот же
      почтовый сервис. ADR-018
- [ ] **Инварианты денег не проверяются в рантайме** — красная линия №5. В `persistence` есть
      проверка `balance < 0` на старте, но после каждой мутации инварианты не считаются. Нужна явная
      функция (сумма балансов константна, hold ≤ available) и решение, что делать в проде: `panic`
      или перевод счёта в read-only. [[ledger]]
- [ ] **Брокер вне журнала событий** — действующее исключение из красной линии №3: состояние
      хранится снапшотами, а не событиями, поэтому видно текущее положение, но не доказуемая история
      его получения. Пока деньги бумажные — приемлемо. Погашение — Фаза 3. [[broker]], ADR-003

### P1 — безопасность и надёжность

- [ ] **Второй фактор (TOTP)** — для брокера практически обязателен. ADR-018
- [ ] **Журнал входов** (когда, откуда, чем) и «выйти со всех устройств». Основа есть: сессии

- [ ] **Блокировка учётной записи из CRM (MICA)** — опирается на тот же отзыв сессий.
- [ ] **Ограничитель попыток входа живёт в памяти процесса** — при распиле на сервисы (Фаза 3)

- [ ] **Нет интеграционных тестов `PgStore`** — покрыты только модульные тесты конверсии денег,

- [ ] **Суммы в JSON — числами**: большие `i128` теряют точность в JavaScript. Кодировать строками.
