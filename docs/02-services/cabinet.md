# Личный кабинет клиента

## Назначение

Кабинет клиента: обзор счёта, позиции и ордера, история сделок, профиль. Отдельный продукт со своим
образом и контейнером (ADR-017). Каталог `apps/cabinet/`, наружу порт **8890**.

## Запуск

```bash
docker compose up --build cabinet   # → http://localhost:8890
```

## Доступ

Решает сервер: на старте `GET /auth/me` по сессионной cookie ([[ADR-018-authentication]]).

- Пока ответ не пришёл — содержимое скрыто, иначе на секунду мелькал бы кабинет с пустыми полями.
- Не вошёл — экран-приглашение со ссылкой на вход. **Форму входа кабинет не дублирует**: она живёт
  на [[site]], и вход там открывает сессию сразу для обоих продуктов.
- В разработке это работает потому, что cookie не различают порт и `localhost:8889` / `:8890`
  делят одну сессию. В продакшене продукты разъедутся по поддоменам, и cookie нужно будет выдавать
  с `Domain=.<домен>` — записано в ADR-018.

## Разделы

- **Обзор** — баланс, средства, занятая маржа, свободно, текущий P&L (из `GET /account`), открытые
  позиции и **пополнение/вывод** (демо-деньги: `POST /account/deposit|withdraw`, проводками через
  брокер; вывод ограничен свободными средствами).
- **Позиции** — открытые позиции (`/deals`) и лимитные ордера (`/pending`).
- **История** — закрытые сделки (`/deals/closed`), новые сверху.
- **Профиль** — почта и номер клиента; безопасность и верификация помечены как недоступные.

Все цифры настоящие, из шлюза; опрос раз в 4 секунды. Деньги форматируются со знаком перед валютой
(`-$0.06`, а не `$-0.06`).

## Состав

- `public/index.html`, `public/style.css` — разметка и своя тема (значения токенов совпадают с
  сайтом, но файл свой: продукты деплоятся независимо).
- `public/dict.js` — словарь EN/RU кабинета.
- `public/cabinet.js` — доступ, загрузка данных, вкладки, язык, тема, выход.
- Общие модули берутся из `apps/shared/` (`i18n.js`, `theme.js`) — см. ADR-017.

## Ограничения / TODO

- **Пополнение/вывод — демо** (виртуальные бумажные деньги). Реальная платёжная часть и хранение
  средств — отдельно, до реальных денег.
- **Верификация (KYC)** — только статус-заглушка «не начата». Потребуется до реальных средств.
- **Смена пароля, второй фактор, журнал входов** — упираются в auth, см. «Технический долг» в [[backlog]].
- Ссылки на сайт и терминал вычисляются как `hostname:8889` / `:8888` — при выкладке за один домен
  заменить на нормальные пути или поддомены.
