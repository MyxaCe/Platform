# ADR-004 — Тулчейн Rust через Docker

## Статус

`accepted`.

## Контекст

Локально Rust не установлен, машина на Windows. Принцип №27: всё воспроизводимо через Docker.

## Решение

Сборка и тесты ядра — через официальный образ `rust`. Локальная установка не требуется.

```bash
# запуск тестов ядра
docker run --rm -e CARGO_TARGET_DIR=/tmp/target \
  -v "C:/Users/user/Desktop/Platform:/app" -w /app \
  rust:slim cargo test --manifest-path core/Cargo.toml
```

`CARGO_TARGET_DIR=/tmp/target` держит артефакты сборки внутри контейнера, чтобы не засорять
рабочую папку каталогом `target/` на Windows-ФС (и это быстрее).

## Последствия

- Нет локального `cargo` — все команды через `docker run` (обёрнуто в `scripts/`).
- Фаза 1 без внешних крейтов → сборка офлайн, без обращения к crates.io.
- Позже (когда появятся зависимости) — добавить кэш-том для реестра/скомпилированных крейтов.
- Для быстрой локальной итерации при желании можно поставить rustup — но это не обязательно.
