# ADR-008 — Оркестратор: путь ордера (резерв → матчинг → расчёт)

> **Снято с живого пути [[ADR-022-standalone-terminal-pivot]] (2026-07-25):** крейты `orchestrator`
> и `core` (matching) удалены. Биржа-стакан может вернуться отдельным продуктом; код — в истории git.

## Статус

`accepted`.

## Контекст

[[matching-engine]] (матчинг) и [[ledger]] (деньги) — два независимых корректных механизма.
Нужен слой, который связывает их в полный путь заявки и гарантирует, что заявка не исполнится
без обеспечения. Это композиция, поэтому — отдельный крейт `orchestrator` (зависит от `domain`,
`exchange_core`, `ledger`; ядро и ledger по-прежнему не знают друг о друге).

## Решение

**Reserve-before-match, settle-from-events.**

1. **Резерв.** До отправки в движок: buy → резерв `quote = цена×объём`, sell → резерв `base = объём`.
   Не хватило — `InsufficientFunds`, движок не трогаем.
2. **Матчинг.** `engine.apply(PlaceOrder)` → события.
3. **Отказ движка** (tick/lot/min/инструмент) → вернуть резерв, `Engine(reason)`.
4. **Расчёт по событиям:**
   - `Trade` → `ledger.settle_fill(...)`; уменьшить остаток резерва участников.
   - `OrderFilled` → заявка исполнена, забыть запись.
   - `OrderCanceledRemainder` / `OrderCanceled` → вернуть остаток резерва.

**Цена резерва покупателя в `settle_fill`:** сделка идёт по цене maker'а `P`.
- taker — покупатель: цена резерва = лимит taker'а `L` (входящая заявка) → возврат `(L−P)·q`.
- maker — покупатель: он стоял по `P`, значит цена резерва = `P` → возврата нет.

**Реестр заявок оркестратора:** `OrderId → { user, side, price, reserved_asset, reserved_remaining }`.
Позволяет найти пользователя и вернуть точный остаток резерва при отмене/остатке.

## Последствия

- Впервые есть полный путь ордера с движением денег (лимитные заявки, обе стороны).
- **Отложено (backlog):** резерв под рыночную заявку (цена неизвестна); предотвращение self-trade
  (сейчас численно корректно, но допускается); журнал событий оркестратора/ledger (Фаза 3).
- Инвариант: `total_supply` актива сохраняется на всём пути (проверяется тестами).
