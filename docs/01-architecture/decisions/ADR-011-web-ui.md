# ADR-011 — Веб-интерфейс (живой стакан + график)

## Статус

`accepted`.

## Контекст

Нужно «увидеть биржу глазами» в браузере: стакан, лента сделок, живой график — на реальных данных
нашего [[gateway]]. Это исходная идея проекта (живые графики как на бирже).

## Решение

- **Статический SPA** (vanilla JS + TradingView Lightweight Charts), без сборщика — библиотека
  вендорится из npm на этапе Docker-сборки (как раньше).
- **nginx** отдаёт статику и **проксирует** `/orders`, `/book`, `/balance`, `/admin`, `/health`,
  `/stream` на `gateway:8080`. Один origin → без CORS. Gateway наружу не публикуется; вход — через web.
- **График строится из потока сделок**: сервер шлёт события (без времени — ядро детерминировано),
  клиент ставит метку времени при получении и агрегирует сделки в свечи по секундным корзинам.
- **Авто-демо** (кнопка): периодически шлёт заявки (alice только продаёт, bob только покупает —
  без self-trade), создавая непрерывный поток сделок, чтобы график двигался сам.

## Последствия

- Два сервиса в compose: `gateway` (внутренний) + `web` (порт 8888).
- Свечи — клиентские и по времени получения (не серверному). Реальные серверные свечи появятся с
  журналом событий (Фаза 3) и историческим эндпоинтом. См. [[backlog]].
- Суммы масштабируются на клиенте (`price_decimals`/`qty_decimals` инструмента).
