# 📍 Статус проекта и что дальше

Точка входа при возобновлении работы (в т.ч. на другой машине / после архивации).
Обновляется в конце каждой рабочей сессии. Карта документации — [[README]].

## Что это теперь (пивот 2026-07-25, ADR-022)

**Автономный торговый терминал** на **реальных ценах Binance** с **бумажными деньгами** —
самодостаточный продукт для встраивания в множество внешних сайтов. Раньше проект был
мультипродуктовой платформой (сайт/вход/кабинет/терминал с аутентификацией и поддоменами) — всё,
что не относится к терминалу, удалено (см. [[ADR-022-standalone-terminal-pivot]]). Сайт платформы
и CMS будут отдельными сущностями и определяются позже.

**Логина нет:** терминал работает сразу, на одном демо-счёте по умолчанию (`DEFAULT_USER`, старт
$100k). Как внешний сайт/CMS будет авторизовать своего пользователя в терминале — **открытый
вопрос**, отдельное будущее решение.

## Структура репозитория

```
backend/                Rust-workspace (4 крейта)
  domain/               типы денег/инструментов (деньги целыми)
  broker/               бумажный брокер: позиции, маржа, P&L, SL/TP, лимитные ордера
  persistence/          счета в PostgreSQL за трейтом Persistence (ADR-016)
  gateway/              axum: feed.rs (данные Binance) + REST/WS терминала
apps/terminal/          терминал: nginx (статика public/ + прокси API/WS на gateway)
docs/  scripts/  docker-compose.yml
```

`docker compose` = **postgres + gateway + terminal**. Наружу торчит только терминал на **:8888**;
он же проксирует API и WS на внутренний gateway. Edge/поддомены/HTTPS сняты — терминал
самодостаточен, TLS остаётся на стороне хоста интеграции.

## Что работает end-to-end (`docker compose up --build` → http://localhost:8888)

- **Данные:** реальные с Binance без ключа (`backend/gateway/src/feed.rs`) — свечи, котировки
  топ-30 пар, лента сделок, стакан, статистика по периодам. Симуляции нет.
- **Брокер** (крейт `broker`): позиции Long/Short, маржа (leverage=1), P&L, SL/TP, лимитные ордера
  с триггером, история закрытых сделок; фоновый монитор 500мс.
- **Состояние durable** (ADR-016): PostgreSQL за трейтом `Persistence` (крейт `persistence`).
  Рестарт ничего не теряет. Без `DATABASE_URL` — `NoopStore` (всё в памяти) — на нём идут тесты.
  После пивота хранятся только счета; таблиц users/sessions/passkeys больше нет.
- **Терминал** (`apps/terminal/public/`): свечи + типы графика + ~35 индикаторов, размер сделки в
  LOT/USD, статистика 1m…1w, инструменты рисования, ресайз панелей, настройки, стакан со своим
  меню. Раскладка: слева стакан, по центру график и BUY/SELL, справа монеты и сделки, внизу
  ордера и история — см. [[web-ui]]. Модули по контракту ADR-015: `api`, `indicators`,
  `orderbook`, `stats`, `watchlist`, `positions`, `trades`, `drawings`; `app.js` — композитор.

Проверено headless (2026-07-25): терминал открывается автономно — график, стакан, watchlist,
баланс $100k, ноль ошибок в консоли. Backend: тесты зелёные, clippy `-D warnings` чист.

Детали по сервисам — [[gateway]], [[broker]], [[web-ui]].

## Что дальше — приоритеты

1. **Сайт платформы и CMS** — владелец определит следующими. Отдельные сущности вне этого ядра.
2. **Интеграция терминала во внешние сайты/CMS** — как передаётся личность пользователя, изоляция
   счетов, авторизация встраивания. Пока `DEFAULT_USER` — единственная личность.
3. **Плечо и ликвидация/margin-call** ([[broker]]): сейчас leverage=1, ликвидации нет. ⚠️ При
   возврате учесть: с плечом баланс может уйти в минус, а проверка инвариантов на старте
   (`balance < 0`, ADR-016) сейчас **фатальна** — политику надо пересмотреть.
4. **Довынести из `app.js`** по ADR-015: панель сделки → клиент-фид → лейаут → график (последним).
5. Прочее — [[backlog]]: Volume Profile/TPO/Fibonacci/ZigZag/Pivot Points, WS-подписки по
   инструменту, суммы строками в JSON, не-крипто рынки (нужен платный провайдер).

## Как запускать и проверять

```bash
docker compose up --build            # → http://localhost:8888
docker compose down --remove-orphans # при рестарте: иначе прилипает старое состояние
bash scripts/test.sh                 # тесты в Docker (rust:slim)
```

- Локального Rust нет — **весь тулчейн через Docker** (ADR-004).
- clippy `-D warnings` — тот же режим локально и в CI.
- **Фронтенд проверять headless-браузером до слова «готово»** (`mcr.microsoft.com/playwright`):
  рендер, консоль без ошибок. Так были пойманы BUG-005/006/007.
- Порты 8080–8282 на рабочей машине заняты WinNAT — наружу используется **8888**.
