# 📍 Статус проекта и что дальше

Точка входа при возобновлении работы (в т.ч. на другой машине / после архивации).
Обновляется в конце каждой рабочей сессии. Карта документации — [[README]].

## Где мы сейчас (2026-07-19)

**Модель продукта:** брокерский терминал на **реальных ценах Binance** с **бумажными деньгами**
(ADR-013 + ADR-014). Не биржа-стакан: matching-ядро есть, но на живом пути не используется.
**Реальных денег нет**, депозиты виртуальные.

Что работает end-to-end (`docker compose up --build` → http://localhost:8888):

- **Данные:** реальные с Binance без ключа (`gateway/src/feed.rs`) — свечи, котировки топ-30 пар,
  лента сделок, стакан, статистика по периодам. Симуляции нет.
- **Брокер** (крейт `broker`): позиции Long/Short, маржа (leverage=1), P&L, SL/TP, лимитные ордера
  с триггером, история закрытых сделок; фоновый монитор 500мс.
- **Терминал** (`web/`): свечи + типы графика + ~35 индикаторов, стакан с кликом в лимитную заявку,
  размер сделки в LOT или USD, статистика 1m…1w, инструменты рисования, ресайз панелей, настройки.

Детали по сервисам — [[gateway]], [[broker]], [[web-ui]]. Решения — ADR-001…ADR-015.

## Принципы разработки приняты (2026-07-19)

[[development-principles]] переведены из `proposed` в **`accepted`** — обязательны для кода и ассистента.
При сверке с кодом: красные линии №1 (деньги целыми), №2 (детерминизм ядра), №4 (один писатель)
соблюдены. №3 (журнал событий) получил **явное действующее исключение для `broker`** со сроком
погашения — Фаза 3, и не позже появления реальных денег. №5 (инварианты в рантайме) фактически не
реализован → в [[backlog]] раздел «Технический долг», туда же попал недоделанный крейт `persistence`.

## Последнее крупное решение: переиспользуемые модули (ADR-015)

Принято: **все модули — самодостаточные и переиспользуемые**; зависимости инъектируются через
контекст, чужие глобалы и id/пути страницы под запретом. Контракт виджета:
`Widget.mount(root, ctx) → { refresh, destroy }`. Закреплено принципом №11 в
[[development-principles]] — **обязательно для всех новых модулей**.

Вынесено (первый заход): `indicators.js` (~35 чистых функций), `orderbook.js`, `stats.js`.
`app.js` стал композитором (464 → 410 строк).

**Второй заход (2026-07-19):** `api.js` (клиент REST — токен и разбор ответов в одном месте, готовит
настоящий auth) и `watchlist.js` (список инструментов целиком: поиск, сортировка, избранное, колонки;
первый виджет, строящий свой DOM). `app.js`: 380 → 339 строк (40.3 → 36.2 КБ), обращений к DOM
страницы 82 → 75. Снижение скромное — основная масса обращений сидит в графике, панели сделки и
нижних вкладках, а они пока не вынесены.
Попутно найдены и исправлены три давних дефекта UI, каждый существовал до рефакторинга:
**BUG-008** (график сыпал `RangeError`, подписи оси зависели от локали ОС клиента), **BUG-009**
(колонки списка налезали друг на друга, тикер схлопывался в 0px), **BUG-010** (тулбар выдавливал
кнопки поверх панели метрик; кнопка price type была полностью некликабельна — её накрывала панель
рисования). Ширина левой панели поднята 280 → 440px: замер показал, что при 280 цены резались,
а полный ноль обрезаний требует 520px и душит график.

**Переиспользуемость закрыта (2026-07-20).** Аудит вскрыл, что развязан был только JS: классы виджетов
жили в общем `style.css` вместе с токенами темы → на чужой странице виджет отрисовался бы голыми
`div`-ами. Теперь **каждый виджет возит свою CSS внутри модуля** и инжектит её сам; токены темы —
контракт хоста, но с фолбэками (`var(--down,#ef5350)`); размещение осталось за хостом; `mount()`
делает первичную отрисовку (раньше виджет молчал без внешнего `refresh()`). `drawings.js` приведён к
контракту: `Drawings.mount(root, cfg)`, `window.__lw` удалён, `chartReload` заменён на `draw.clear()`.
Проверено: виджет монтируется одной строкой на странице **без единого `<link rel=stylesheet>`** и
отрисовывается полностью. Таблица статусов — в [[ADR-015-reusable-frontend-modules]].

**Нижняя панель вынесена (2026-07-20):** `positions.js` (вкладки сделок/ордеров/истории/сигналов).
Позиции отдаются хосту колбэком (график сам рисует SL/TP-линии), сигналы приходят снаружи — считает
их хост из свечей.

Осталось вынести из `app.js`: панель сделки, клиент-фид (WS + интервалы), лейаут/настройки, график.

## Что дальше — приоритеты

1. **Персистентность — PostgreSQL ([[ADR-016-persistence-postgres]], `accepted` 2026-07-20).** Сейчас
   всё состояние в RAM: рестарт обнуляет позиции, балансы, историю и пользователей. Реализовать крейт
   `persistence` **с нуля** по ADR-016: трейт `Persistence`, `sqlx` без макросов `query!`, деньги
   `NUMERIC(38,0)` (i128 не влезает в 64-битный INTEGER — поэтому не SQLite), брокер остаётся
   in-memory и синхронным, БД — durable-проекция. Начать с изменения `Broker::check()` → возвращает
   `Vec<UserId>` затронутых счетов. Делать **до** плеча/ликвидации.
   Черновик `persistence/` от оборванной сессии **удалён** 2026-07-20 (не компилировался, не был
   подключён) — начинать с чистого листа.
2. **Перенос остальных фронтенд-модулей на паттерн ADR-015** (по убыванию выгоды): watchlist →
   панель сделки → клиент-фид (WS+поллинг) → лейаут/настройки → **график последним** (самый крупный
   и рискованный).
3. **Брокер:** плечо, ликвидация/margin-call, комиссии, свопы.
4. **Фаза 3:** журнал событий на всю платформу (durable аудит), распил на сервисы.
5. Прочее — [[backlog]]: Volume Profile/TPO/Fibonacci/ZigZag/Pivot Points, настоящий auth,
   WS-подписки по инструменту, суммы строками в JSON, не-крипто рынки (нужен платный провайдер).

## Как запускать и проверять

```bash
docker compose up --build            # → http://localhost:8888
docker compose down --remove-orphans # при рестарте: иначе прилипает старое состояние
bash scripts/test.sh                 # тесты в Docker (rust:slim) + clippy -D warnings
```

- Локального Rust нет — **весь тулчейн через Docker**.
- **Фронтенд проверять headless-браузером до слова «готово»** (образ
  `mcr.microsoft.com/playwright`, `playwright-core`): рендер, консоль без ошибок. Так были пойманы
  BUG-005/006/007.
- **Новый REST-путь → добавить в регекс прокси `web/nginx.conf`** (BUG-004). Регекс имеет границу
  `(/|$)`, чтобы статика с тем же префиксом не уезжала в прокси (BUG-007).
- Порты 8080–8282 на рабочей машине заняты WinNAT — наружу используется **8888**.
