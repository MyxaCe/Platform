# Theming-пакет платформы · v1

Контракт темизации для потребителей White Label (терминал — первый). Три файла:

| Файл | Что это |
| --- | --- |
| `tokens.v1.css` | Дизайн-токены платформы — единственный источник цвета. Версионируется: изменения только аддитивные, ломающие → `tokens.v2.css` |
| `cms.brand.schema.json` | JSON Schema ответа `GET /v1/cms/brand` (draft-07) |
| `brand.example.json` | Живой пример ответа (снят с работающей CMS) |

## Правила токенов

1. **Цвета — RGB-каналы без `rgb()`**: `--accent: 212 164 55`. Использование: `rgb(var(--accent))`, с прозрачностью — `rgb(var(--accent) / 0.1)`. Исключение: `--border` — готовое `rgb(... / a)` значение.
2. **Темы — атрибутом `data-theme`** на корневом элементе: `dark` (по умолчанию, `:root`) и `light`. Переключение темы = смена атрибута, никаких пересборок.
3. **Шрифт**: семейство приходит переменной `--font-sans` (потребитель задаёт свою; наши приложения используют Inter). Fallback: `system-ui, sans-serif`.

## Рантайм-брендирование (порядок загрузчика)

1. Подключить `tokens.v1.css` (базовая палитра платформы, обе темы).
2. Запросить `GET {CMS_API_URL}/v1/cms/brand?locale={locale}` с заголовком `X-API-Key` (ключ выдаём мы; на этапе Т1 — общий, с этапа Т2 добавится `?site=`).
3. Применить поверх токенов:
   - `primaryColor` (hex `#rrggbb`) → перевести в каналы и записать `--accent` (hover можно вычислить осветлением +10–12% или оставить базовый);
   - `logo` (`{url,width,height,alt,mimeType} | null`) → логотип в шапке; `null` → текстовый фолбэк (первая буква `name`);
   - `name` → подпись бренда/`<title>`.
4. Ответ обязателен к валидации схемой (`cms.brand.schema.json`); невалидный ответ → остаться на текущем бренде (никогда не «раскрашиваться» мусором). Кешировать последний валидный ответ (наш паттерн last-good).
5. Частота обновления: раз в 5 минут или по перезагрузке страницы — достаточно; вебхук-инвалидация не требуется.

## Версионирование

- Файл токенов immutable по мажору: `tokens.v1.css` не меняет и не удаляет существующие переменные; новые добавляются с фолбэками.
- Канон пакета переедет в `platform-contracts` вместе с остальными схемами; до тех пор источник — этот каталог в репо Sait_Platform.

## Соответствие каналов Tailwind-именам (для справки)

`--bg-base`→фон страницы · `--bg-elevated`→панели · `--bg-card`→карточки/инпуты · `--accent`(+`-hover`)→акцент бренда · `--text-primary`/`--text-secondary`→текст · `--positive`/`--negative`→рост/падение (график, P&L!) · `--royal`→вторичный брендовый · `--border`→границы.
